## 1. 结构化数据路由

先确认当前环境可调用且已获授权的金融数据技能或API，并读取其路由说明和帮助输出，不凭记忆拼参数。若安装了 `westock-data`，完整读取 `westock-data/SKILL.md` 及其路由说明；若没有，则使用交易所、监管机构、上市公司公告等官方一手资料，并把结构化字段缺口列为待核验。

建议顺序：

1. 搜索公司名称，确认市场前缀和代码；
2. 财务：利润表、资产负债表、现金流，近三年一期；
3. 公告：年报、季报、质押、担保、关联交易、诉讼；
4. 股东、质押和减持；
5. K 线、技术指标、估值/一致预期；
6. 可比公司财务一次批量取数。

若网络失败，申请允许后原命令重试。不要切换到低质量网页行情补同一字段；官方一手披露可用于核验，但要标明日期、口径和无法取得的字段。

## 2. 报表口径

- 采用合并报表；利润用归母净利润，另列扣非时不可混入归母口径。
- 年报标注审计意见；中报和季报标注未经审计。
- 财务表中的 `BillAccReceivable`、`NotAccountsPayable` 等聚合字段需要在报告中解释为“票据+账款”；涉及风险判断时回到审计附注拆分。
- 同业比较所有公司使用同一报告期、同一币种、同一单位和同一字段。
- 期末存量与期间流量不可直接相除解释周转，除非使用期初期末平均余额。

## 3. 核心公式

```text
毛利率 = (营业收入 - 营业成本) / 营业收入
归母净利率 = 归母净利润 / 营业收入
资产负债率 = 总负债 / 总资产
流动比率 = 流动资产 / 流动负债
速动比率 = (流动资产 - 存货) / 流动负债
现金转换率 = 经营活动现金流净额 / 归母净利润
收入增速 = 当期收入 / 上期收入 - 1
应收增速阈值 = 收入增速 × 1.5
Q4 单季值 = 年度累计值 - 三季度累计值
TTM 净利润 = 最新报告期累计值 + 上年全年值 - 上年同期累计值
市值 = 截至日收盘价 × 截至日总股本
PE-TTM = 市值 / TTM 归母净利润
PB = 市值 / 最近一期归母净资产
最大回撤 = min(收盘价 / 此前历史最高收盘价 - 1)
单一股东持股质押比例 = 该股东质押股数 / 该股东持股数
公司总质押率 = 全部质押股数 / 公司总股本
```

计算规则：

- 保留原始精度，最后展示时再四舍五入；表格尾差注明原因。
- 负净利润下 CFO/净利润不具有常规解释，应改用绝对差额和累计现金流。
- “应收”阈值应分别看应收账款、票据+账款和合同资产，不可只选对结论有利的口径。
- 最大回撤应使用按时间推进的历史峰值，不可简单用区间最高/最低替代；若报告使用峰谷跌幅，必须准确命名。
- 年化波动率说明使用日收益标准差及交易日因子，复权方式一致。

## 4. 股价与质押

- 行情截止日应为最近已收盘交易日；周末/节假日报告要说明。
- K 线复权方式在区间内保持一致；质押市值和处置金额通常使用不复权实际价格。
- 质押公告、股东名册和市场汇总可能处于不同日期。做比率前先对齐：股数、总股本、股东持股和质押余额。
- 公司总质押率低但单一股东持股质押比例高时，突出出质人层风险。
- 延期购回不等于新增融资；解除质押不等于出质人整体债务已清偿。
- “公告称不存在平仓风险”只是公司/股东陈述，不能替代融资余额、警戒线和补仓能力。

## 5. 证据边界

### 可作为事实

- 公司/交易所/监管机构原文；
- 政府、行业协会统计；
- 统一口径的权威金融数据库字段；
- 本报告基于上述数据的可复核计算。

### 只能作为辅助解释

- 券商研报的行业判断、盈利预测、汇兑或产品结构解释；
- 财经媒体对技术路线和供应链的报道。

### 只能作为舆情线索

- 股吧、雪球、自媒体；
- 投资者向公司的提问中包含但公司未确认的数字；
- 搜索引擎摘要中的孤立数字。

### 禁止

- 把本地旧报告、截图或缓存当作最新金融事实；
- 在来源不可访问或内容不一致时自行补全；
- 把“未检索到”写成“绝对不存在”；
- 未知融资参数下给具体预警线、平仓线或质押率建议。

## 6. 交付质检

检查顺序：

1. 报告顶部有软件、AI、研究日、财务/行情截止日；
2. 全部必需章节存在；
3. 关键表格带单位、期间、来源；
4. 十项预警均有状态；
5. 主体、出质人、抵押品、处置四层结论分开；
6. 来源链接可打开，搜索摘要已回到正文；
7. “待核验”与“未触发”没有混用；
8. 未编造客户、份额、融资参数；
9. 运行 `scripts/validate_report.py`；
10. 如交付 Obsidian 或其他副本，副本与工作区成品 SHA-256 完全一致，且报告正文不含本机绝对路径或个人环境信息。
